The two builds

About

Street Fighter Alpha 2 EX builds on our Street Fighter Alpha 2 Gold backport. Every Gold fighter plays exactly as in Gold. EX adds the menus, modes and forms the arcade game kept behind codes or never had, and every secret starts unlocked.

In CONSOLE game mode the game plays free, and START at the title opens a mode menu: Arcade, Versus, Survival, Dramatic Battle, Akuma and Options. Versus matches go straight back to the select screen, and holding START for three seconds on any select screen returns to the menu. Cammy and a Random cell sit on the select screen, Cammy turns up as a CPU opponent in the other fighters' Arcade runs, and alternate forms take a START press or two instead of five.

Two EX forms join the roster, each one START press away on its fighter's cell: EX Akuma and EX Cammy. Both follow Capcom's own EX rules, with classic moves and no Super Combos.

OPTIONS opens an OPTION MODE page with difficulty, time limit, rounds, damage, turbo and sound. The operator menu adds GAME MODE, eight GAME SPEED levels and a TIME LIMIT of 25, 50, 75, 99 or infinity, and the title has a new EX mark. The USA build is in English; the Japan build, Street Fighter Zero 2 EX, keeps the Japanese.

The MiSTer MRAs start in CONSOLE mode. MAME and HBMAME start in ARCADE mode, which keeps Gold's arcade title; set GAME MODE to CONSOLE on the operator menu's SYSTEM page for the mode menu. It runs in MAME and HBMAME and on MiSTer.

This is a release candidate.

How it's distributed

Each build is put together on your own machine from files you already own. You need:

  • your own PlayStation 2 anthology disc image: Street Fighter Alpha Anthology for the USA set, or Street Fighter Zero — Fighter's Generation for the Japan set
  • your own arcade Street Fighter Zero 2 Alpha romset: sfz2al for the USA set, sfz2alj for the Japan set

A small tool reads Alpha 2 Gold from your PlayStation 2 disc image, combines it with your arcade Zero 2 Alpha romset, adds EX, and writes out the finished CPS-2 build.

Two sizes of each build are produced. A 4 MB set stays within original CPS-2 limits and runs on real hardware and stock MAME. It carries all of Cammy's voices and sound effects, with some downsampled to fit. An 8 MB set carries the same audio at full quality, for HBMAME and MiSTer (Jotego's jtcps2 core).

Merged, split and complete archives and extracted ROM folders are accepted. Use --rompath /path/to/roms (repeatable) and --check to verify arcade inputs before rebuilding from your disc. 7z needs installed 7-Zip; ZIP does not.

Notes

  • The 8 MB builds hold more QSound audio than the original CPS-2 hardware supports, so they run only on HBMAME and MiSTer.
  • The 4 MB builds use the same arcade set names as Street Fighter Alpha 2 Gold's 4 MB builds (sfz2al, sfz2alj), so keep one or the other in your MAME ROM path.
  • This is a fan edition, unaffiliated with Capcom. The sets are built from discs and roms you already own, and the kit ships no code or data from the anthology or the arcade game beyond EX's mirrored and recolored versions of some of the game's own art. It also carries a few small pieces of other Capcom games: about 4 KB of Cammy's theme score from X-Men vs. Street Fighter (1996), for her stage music; the infinity and star symbols from Street Fighter Zero 2 Dash for the Sega Saturn; and a few bytes of projectile data from Super Street Fighter II Turbo.
