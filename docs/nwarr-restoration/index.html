About this patch

Night Warriors left a lot of Vampire Hunter behind. Every export version skips the epilogue that follows each ending. The endings were rewritten, with different page counts on most routes, and each fighter gets a handful of fixed win quotes where the Japanese game picks from a much larger pool.

The English Restoration brings back all 14 epilogues, rebuilds the 112 ending pages with the Japanese scenes and pacing, and restores the full pool of 323 win quotes, all translated from the Japanese.

Sasquatch’s Japanese victory poses and their sounds are back, along with Morrigan’s and Donovan’s extra win sounds.

It keeps the Night Warriors title, the Western character names and the English operator menu with the USA settings. It runs in MAME and HBMAME and on MiSTer.

This is a release candidate.

What's changed

  • All 14 epilogues after the endings, in English; every export version skipped them
  • The 112 Japanese ending pages in English, with the Japanese scenes and pacing
  • The full pool of 323 Japanese win quotes in English, picked as in Japan
  • Sasquatch’s Japanese victory poses and sounds, and Morrigan’s and Donovan’s extra win sounds
  • The Night Warriors title, Western character names and the USA operator menu

Spot a difference we missed?

A restoration is only as complete as its list of differences. If the Japanese version does something this one still doesn't, whether a line of text, a scene, a screen or a small detail, please let us know. Anything you find goes into the next release.

You need your own dump of Vampire Hunter: Darkstalkers' Revenge (Japan 950316) as the MAME set vhuntj.zip. Each zip includes a readme.txt with full instructions.

Merged, split and complete sets work, including nested or renamed ROMs. Use --rompath /path/to/roms to search a collection (repeatable), and --check to check inputs before building. ZIPs and extracted folders need no extra software; 7z archives require 7-Zip. QSound can stay in your emulator's ROM path; valid firmware already embedded in a source set is kept in complete outputs.

How to apply

unzip nwarr-restoration-rc1-ips.zip -d vhuntj-patch
cd vhuntj-patch
python3 apply.py /path/to/vhuntj.zip --out-dir out

The script checks every file against the checksums below, applies the patches, checks the result, and writes the files for every platform in one go:

out/mame/vhuntj.zip
out/hbmame/nwarrru.zip
out/mister/_Arcade/_Arcade Patches/_Restorations/Night Warriors Darkstalkers' Revenge (USA) [English Restoration].mra

MAME and original hardware. Put the zip from out/mame/ ahead of the stock set in your MAME rompath (it keeps the name vhuntj.zip), or burn its ROM files. MAME's game menu won't start a set with patched ROMs, so start it from the command line: mame vhuntj. MAME shows checksum warnings for the patched ROMs. That's expected, and the game runs normally. To start it from a menu, use the HBMAME build.

HBMAME. Put the zip from out/hbmame/ in HBMAME's roms/ folder together with qsound.zip; it holds the complete set. It loads with no checksum warnings. This restoration is an official HBMAME set, nwarrru, so full HBMAME collections may already carry it.

MiSTer. Copy the _Arcade folder from out/mister/ to the root of your SD card, and keep the stock, unmodified romset at games/mame/vhuntj.zip (split MAME sets also need qsound.zip). You need Jotego's jtcps2 core, which update_all installs. The MRA applies the restoration in memory as the game loads, so nothing on your card is modified, and it keeps its own settings and saves under nwarrru. The MiSTer-only download holds the same MRAs, ready to copy.

Any IPS patcher. Apply each file in ips/ (Flips, Lunar IPS, …) to the ROM file of the same name and re-zip the set yourself.
