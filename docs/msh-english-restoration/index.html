About this patch

This USA edition brings the Japanese 951117 arcade script to English. Victory quotes, continue prompts, Automode tips and endings have been retranslated.

What's changed

  • Read the Japanese revision’s victory quotes, continue prompts, Automode tips and endings in English.
  • Unlock Doctor Doom, Thanos and Anita with their original Japanese codes. Anita has a nameplate on both lifebars.
  • Both outcomes of Thanos’s ending retain their original timing.

The kit is our reconstruction code and a short list of byte patches. Everything else is rebuilt on your machine from files you already own.

What you supply

  • Your stock arcade ROMs for the MAME set mshj.
  • The standard QSound firmware for MAME, HBMAME and MiSTer.

Build or update

Extract the kit, open a terminal in its folder, and run:

python3 apply.py

On Windows, use py -3.13 apply.py. Choose Build or update, then select your media folders and available outputs. Your media can stay where it is. The kit remembers your choices and prepares required helpers and Python packages privately on supported systems. Read INSTALL.txt in the completed output for the files to copy. Run the same command again to update.

Advanced command-line reference

How to build

unzip msh-english-restoration-rc1-kit.zip -d msh-english-restoration
cd msh-english-restoration
python3 apply.py --rompath /path/to/roms --out-dir out

Darksoft CPS-2

The kit can build Darksoft CPS-2 flash files. Build them with --platform darksoft --out-dir out, then copy the selected game folder from out/darksoft/games/ to the card's games/ folder. Keep its flash files, key and NAME together. Follow the kit readme for build choices.
