About this patch

X-Men vs. Street Fighter’s Japanese release has more to say. This restoration brings its full victory quotes, Apocalypse dialogue, endings and tips into English while keeping the Japanese fighting rules.

The USA presentation uses Western fighter names and regional voices. Text is centered in the game’s original dialogue and ending panels.

It runs on Darksoft CPS-2 hardware, on MiSTer, and in MAME. HBMAME and FBNeo outputs use the same game data.

This is a release candidate.

What's changed

  • All 288 win quotes in English, including Apocalypse’s sixteen quotes.
  • All 54 Apocalypse dialogue passages, 104 ending captions and seventeen tips in English.
  • Western fighter names and USA regional voices, with Japanese 970113 gameplay.
  • Centered English text and complete ending illustrations.

Spot a difference we missed?

A restoration is only as complete as its list of differences. If the Japanese version does something this one still doesn't, whether a line of text, a scene, a screen or a small detail, please let us know. Anything you find goes into the next release.

Build or update

Extract the kit, open a terminal in its folder, and run:

python3 apply.py

On Windows, use py -3.13 apply.py. Choose Build or update, then select your media folders and available outputs. Your media can stay where it is. The kit remembers your choices and prepares required helpers and Python packages privately on supported systems. Read INSTALL.txt in the completed output for the files to copy. Run the same command again to update.

For MiSTer only, the separate MRA download can be used with your stock ROMs. The guided kit builds complete platform folders.

Advanced command-line reference

How to apply

unzip xmvsf-restoration-rc1-ips.zip -d xmvsfj-patch
cd xmvsfj-patch
python3 apply.py /path/to/xmvsfj.zip --out-dir out

The script checks every file against the checksums below, applies the patches, checks the result, and writes the files for every platform in one go:

out/mame/xmvsfj.zip
out/hbmame/xmvsfre.zip
out/fbneo/xmvsfre.zip
out/mister/_Arcade/_Arcade Patches/_Restorations/X-Men vs. Street Fighter (USA) [Restoration].mra

MAME and original hardware. Put the zip from out/mame/ ahead of the stock set in your MAME rompath (it keeps the name xmvsfj.zip), or burn its ROM files. MAME's game menu won't start a set with patched ROMs, so start it from the command line: mame xmvsfj. MAME shows checksum warnings for the patched ROMs. That's expected, and the game runs normally. To start it from a menu, use the HBMAME build.

HBMAME. Put the zip from out/hbmame/ in HBMAME's roms/ folder together with qsound.zip; it holds the complete set. It loads with no checksum warnings. The HBMAME set definition (xmvsfre) is generated with the restoration; an upstream submission is pending, so for now you add it to your own HBMAME build.

FBNeo. The kit produces the sets xmvsfre. Put the ZIPs from out/fbneo/ in your FBNeo ROM folder, keeping their ZIP and ROM filenames. These contain the complete game ROMs. Use an FBNeo version with definitions matching this game release. To build only the FBNeo sets, use --platform fbneo --out-dir out.

MiSTer. Copy the _Arcade folder from out/mister/ to the root of your SD card, and keep the stock, unmodified romset at games/mame/xmvsfj.zip (split MAME sets also need qsound.zip). You need Jotego's jtcps2 core, which update_all installs. The MRA applies the restoration in memory as the game loads, so nothing on your card is modified, and it keeps its own settings and saves under xmvsfre. The MiSTer-only download holds the same MRAs, ready to copy.

Any IPS patcher. Apply each file in ips/ (Flips, Lunar IPS, …) to the ROM file of the same name and re-zip the set yourself.

Darksoft CPS-2

The kit can build Darksoft CPS-2 flash files. Build them with --platform darksoft --out-dir out, then copy the selected game folder from out/darksoft/games/ to the card's games/ folder. Keep its flash files, key and NAME together. Follow the kit readme for build choices.
