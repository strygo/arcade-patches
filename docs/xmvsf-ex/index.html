About this patch

X-Men vs. Street Fighter EX keeps the arcade tag-team game and adds a home-style Console mode. Start opens a title menu with Arcade, Versus, Training and Options. Versus supports a friend or the computer, with handicap and stage choices and win totals that carry through rematches. Training offers dummy, guard, gauge, speed and stage controls.

Apocalypse is fully playable: he fights alone in his own arena with his six native commands, has a seven-fight Arcade route with Magneto and M. Bison as the final opponents, and gets his own ending. Akuma and Apocalypse have visible places on character select. The other fighters get the Saturn version's two extra colors, carried through portraits and effects, and mirror matches keep both sides' colors distinct. Holding Start on Chun-Li previews her alternate outfit.

The USA build includes the English Restoration: win quotes translated from the Japanese, restored Apocalypse conversations and complete endings. The Japan build keeps the original Japanese text and adds Japanese for Apocalypse's final conversation, his ending and the service menus. Both builds share the Japanese release's default settings, eight Turbo levels and the original Normal speed. Console mode needs no credits; the service menu also retains ordinary Arcade operation.

This is a release candidate.

What's changed

  • Fully playable Apocalypse with his six native commands, a solo Arcade route with Magneto and M. Bison as the final opponents, and his own ending; visible Akuma and Apocalypse select spaces
  • Console mode with Arcade, Versus, Training and Options; MiSTer starts in Console mode
  • Updated stage select in Versus and Training, with previews and inline handicap
  • Two extra Saturn colors for the ordinary fighters, with matching portraits and effects, and correct colors in mirror matches; select with HP or HK
  • Full English Restoration content in the USA build: win quotes translated from the Japanese, restored Apocalypse conversations, complete endings and speaker labels
  • Pause with Coin or a Start hold, immediate Quit to the title, and Options settings that persist
  • Japan build with the original Japanese text, a Japanese Apocalypse conversation and ending, and Japanese service menus
  • Hold Start on Chun-Li for about two seconds to preview her alternate outfit; eight Turbo levels plus Normal

Build or update

Extract the kit, open a terminal in its folder, and run:

python3 apply.py

On Windows, use py -3.13 apply.py. Choose Build or update, then select your media folders and available outputs. Your media can stay where it is. The kit remembers your choices and prepares required helpers and Python packages privately on supported systems. Read INSTALL.txt in the completed output for the files to copy. Run the same command again to update.

For MiSTer only, the separate MRA download can be used with your stock ROMs. The guided kit builds complete platform folders.

Advanced command-line reference

How to apply

unzip xmvsf-ex-rc1-ips.zip -d xmvsfj-patch
cd xmvsfj-patch
python3 apply.py /path/to/xmvsfj.zip --out-dir out

The script checks every file against the checksums below, applies the patches, checks the result, and writes the files for every platform in one go: (add --variant usa to make just one build)

USA:
  out/mame/usa/xmvsfj.zip
  out/hbmame/xmvsfex.zip
  out/fbneo/xmvsfex.zip
  out/mister/_Arcade/_Arcade Patches/_Enhanced Versions/X-Men Vs. Street Fighter EX (USA).mra
Japan:
  out/mame/japan/xmvsfj.zip
  out/hbmame/xmvsfexj.zip
  out/fbneo/xmvsfexj.zip
  out/mister/_Arcade/_Arcade Patches/_Enhanced Versions/X-Men Vs. Street Fighter EX (Japan).mra

MAME and original hardware. Put the zip from out/mame/ ahead of the stock set in your MAME rompath (it keeps the name xmvsfj.zip, so use one build at a time), or burn its ROM files. MAME's game menu won't start a set with patched ROMs, so start it from the command line: mame xmvsfj. MAME shows checksum warnings for the patched ROMs. That's expected, and the game runs normally. To start it from a menu, use the HBMAME build.

HBMAME. Put the zip from out/hbmame/ in HBMAME's roms/ folder together with qsound.zip; it holds the complete set. It loads with no checksum warnings. The HBMAME set definition (xmvsfex and xmvsfexj) is generated with the patch; an upstream submission is pending, so for now you add it to your own HBMAME build.

FBNeo. The kit produces the sets xmvsfex, xmvsfexj. Put the ZIPs from out/fbneo/ in your FBNeo ROM folder, keeping their ZIP and ROM filenames. These contain the complete game ROMs. Use an FBNeo version with definitions matching this game release. To build only the FBNeo sets, use --platform fbneo --out-dir out.

MiSTer. Copy the _Arcade folder from out/mister/ to the root of your SD card, and keep the stock, unmodified romset at games/mame/xmvsfj.zip (split MAME sets also need qsound.zip). You need Jotego's jtcps2 core, which update_all installs. The MRA applies the patch in memory as the game loads, so nothing on your card is modified, and each build keeps its own settings and saves under its own setname. The MiSTer-only download holds the same MRAs, ready to copy.

Any IPS patcher. Apply each file in ips/<variant>/ (Flips, Lunar IPS, …) to the ROM file of the same name and re-zip the set yourself.
