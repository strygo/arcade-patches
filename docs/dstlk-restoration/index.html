About this patch

The original Japanese Vampire gives each fighter a pool of win quotes, and offers move advice after a loss. The USA version uses one English win quote per fighter and removes the advice.

The English Restoration brings back the Japanese quote pools and bordered result panel, the complete ending dialogue, and all 85 continue tips, translated from the Japanese.

The voices the USA version muted are back: Morrigan’s alternate victory, Vector Drain and throw, and Felicia’s Rolling Buckler, Dancing Flash and special damage reaction. As in the USA release, Rikuo’s crouching heavy punch can be blocked with a crouching guard.

It keeps the ten playable fighters and the Western character names, and adds Free Play to the operator menu. It runs in MAME and HBMAME and on MiSTer.

This is a release candidate.

What's changed

  • Japanese win-quote pools in English, with the Japanese result-panel border
  • Complete Japanese ending dialogue in English, with the original scene timing
  • All 85 Japanese continue tips in English, including their arcade move commands
  • Morrigan’s alternate victory, Vector Drain and throw voices, and Felicia’s Rolling Buckler, Dancing Flash and special damage voices
  • Rikuo’s crouching heavy punch can be blocked with a crouching guard, as in the USA release
  • Western character names, and Free Play in the operator menu

Spot a difference we missed?

A restoration is only as complete as its list of differences. If the Japanese version does something this one still doesn't, whether a line of text, a scene, a screen or a small detail, please let us know. Anything you find goes into the next release.

Build or update

Extract the kit, open a terminal in its folder, and run:

python3 apply.py

On Windows, use py -3.13 apply.py. Choose Build or update, then select your media folders and available outputs. Your media can stay where it is. The kit remembers your choices and prepares required helpers and Python packages privately on supported systems. Read INSTALL.txt in the completed output for the files to copy. Run the same command again to update.

For MiSTer only, the separate MRA download can be used with your stock ROMs. The guided kit builds complete platform folders.

Advanced command-line reference

How to apply

unzip dstlk-restoration-rc1-ips.zip -d vampj-patch
cd vampj-patch
python3 apply.py /path/to/vampj.zip --out-dir out

The script checks every file against the checksums below, applies the patches, checks the result, and writes the files for every platform in one go:

out/mame/vampj.zip
out/hbmame/vamprest.zip
out/fbneo/vamprest.zip
out/mister/_Arcade/_Arcade Patches/_Restorations/Darkstalkers The Night Warriors (USA) [English Restoration].mra

MAME and original hardware. Put the zip from out/mame/ ahead of the stock set in your MAME rompath (it keeps the name vampj.zip), or burn its ROM files. MAME's game menu won't start a set with patched ROMs, so start it from the command line: mame vampj. MAME shows checksum warnings for the patched ROMs. That's expected, and the game runs normally. To start it from a menu, use the HBMAME build.

HBMAME. Put the zip from out/hbmame/ in HBMAME's roms/ folder together with qsound.zip; it holds the complete set. It loads with no checksum warnings. This restoration is an official HBMAME set, vamprest (merged upstream), so full HBMAME collections may already carry it.

FBNeo. The kit produces the sets vamprest. Put the ZIPs from out/fbneo/ in your FBNeo ROM folder, keeping their ZIP and ROM filenames. These contain the complete game ROMs. Use an FBNeo version with definitions matching this game release. To build only the FBNeo sets, use --platform fbneo --out-dir out.

MiSTer. Copy the _Arcade folder from out/mister/ to the root of your SD card, and keep the stock, unmodified romset at games/mame/vampj.zip (split MAME sets also need qsound.zip). You need Jotego's jtcps2 core, which update_all installs. The MRA applies the restoration in memory as the game loads, so nothing on your card is modified, and it keeps its own settings and saves under vamprest. The MiSTer-only download holds the same MRAs, ready to copy.

Any IPS patcher. Apply each file in ips/ (Flips, Lunar IPS, …) to the ROM file of the same name and re-zip the set yourself.
