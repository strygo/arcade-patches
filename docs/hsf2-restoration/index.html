About this patch

Play the Japanese version of Hyper Street Fighter II in English, with its original balance and the classic versions of each fighter. Western fighter names and the official US regional move voices accompany English win quotes, full endings, illustrated Continue tips and all 28 Start messages.

Stage and portrait artwork repairs, black backgrounds in affected ending and Ryu intro scenes, and a clearer ending-choice menu complete the restoration. Japan's factory speed and coin settings are retained, with native Free Play available in the operator menu.

It runs on MiSTer and in HBMAME or FBNeo builds that include hsf2re. Apply the patch to your stock Japanese set.

This is a release candidate.

What's changed

  • Japanese 040202 gameplay and classic fighter versions
  • Western fighter names and official US regional move voices
  • English win quotes, full endings and illustrated Continue tips
  • All 28 Start-message choices in English
  • Stage and portrait artwork repairs, black backgrounds in affected ending and Ryu intro scenes, and a clearer ending-choice menu
  • Native operator Free Play with saved settings and no-coin starts

You need your own dump of Hyper Street Fighter II: The Anniversary Edition (Japan 040202) as the MAME set hsf2j.zip. Each zip includes a readme.txt with full instructions.

Merged, split and complete sets work, including nested or renamed ROMs. Use --rompath /path/to/roms to search a collection (repeatable), and --check to check inputs before building. ZIPs and extracted folders need no extra software; 7z archives require 7-Zip. QSound can stay in your emulator's ROM path; valid firmware already embedded in a source set is kept in complete outputs.

How to apply

unzip hsf2-restoration-rc1-ips.zip -d hsf2j-patch
cd hsf2j-patch
python3 apply.py /path/to/hsf2j.zip --out-dir out

The script checks every file against the checksums below, applies the patches, checks the result, and writes the files for every platform in one go:

out/hbmame/hsf2re.zip
out/fbneo/hsf2re.zip
out/mister/_Arcade/_Arcade Patches/_Restorations/Hyper Street Fighter II The Anniversary Edition (USA) [English Restoration].mra
out/mister/games/hbmame/hsf2re.zip

This kit provides HBMAME and FBNeo outputs. Use emulator builds containing the hsf2re set.

HBMAME. Put the zip from out/hbmame/ in HBMAME's roms/ folder together with qsound.zip; it holds the complete set. It loads with no checksum warnings. Use a HBMAME build containing the hsf2re set definition.

FBNeo. The kit produces the sets hsf2re. Put the ZIPs from out/fbneo/ in your FBNeo ROM folder, keeping their ZIP and ROM filenames. These contain the complete game ROMs. Use an FBNeo version with definitions matching this game release. To build only the FBNeo sets, use --platform fbneo --out-dir out.

MiSTer. Copy the _Arcade folder from out/mister/ to the root of your SD card, and keep the stock, unmodified romset at games/mame/hsf2j.zip (split MAME sets also need qsound.zip). You need Jotego's jtcps2 core, which update_all installs. The MRA applies the restoration in memory as the game loads, so nothing on your card is modified, and it keeps its own settings and saves under hsf2re. The MiSTer-only download holds the same MRAs, ready to copy.

out/mister/games/hbmame/hsf2re.zip is a complete copy of the emulator set. The supplied MRA uses the stock Japanese set; that extra ZIP is optional.
