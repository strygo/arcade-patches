# Arcade Patches

Translations, restorations, enhancements and arranged soundtracks for classic
arcade games. Build patches with your own game media for supported hardware,
MiSTer and emulators.

Visit [Arcade Patches](https://arcadepatches.com/) for games, downloads,
requirements and installation instructions. [ArcadePatches](https://arcadepatches.com/arcadepatches/)
can build and update a collection from media you own.

Report problems in [Issues](https://github.com/strygo/arcade-patches/issues).
Include the game and version, platform, steps to reproduce, expected and observed
behavior, and useful screenshots or logs. Do not attach ROMs or copyrighted media.
